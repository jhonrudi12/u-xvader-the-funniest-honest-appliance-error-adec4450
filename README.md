One line of at most 200 characters: the funniest honest error message an appliance could show. A washing machine, a fridge, a toaster, a boiler or anything else in the house will do, and the line has to be something the machine could plausibly say when it fails, so the laugh comes out of the truth of the fault rather than a pun bolted on.

## Run it

```sh
OUTPUT_DIR=output node main.ts
```

This writes the single entry line to `output/entry.txt`.
